# Погода

Статичний сайт погоди (HTML + CSS + JS), без сервера й збірки. Дані — з [Open-Meteo](https://open-meteo.com/).

## Як виставити на GitHub Pages

1. Створіть репозиторій на GitHub і завантажте **весь вміст цієї папки** (файл `index.html` має лежати в корені репозиторію).
2. **Settings → Pages → Build and deployment → Source: Deploy from a branch**, Branch: `main`, folder: **`/ (root)`** → Save.
3. Через 1–2 хвилини сайт відкриється на `https://<ваш-логін>.github.io/<репозиторій>/`.

## Що зберігається в браузері (localStorage)

- мова інтерфейсу, список збережених міст, останнє переглянуте місто;
- якщо ви дозволили доступ до місцезнаходження — при кожному заході сайт визначає його й показує погоду для вашого місця (поки визначається, миттєво показується останнє місто).

Геолокація й service worker працюють лише по HTTPS — GitHub Pages його дає автоматично.

## Структура

```
index.html, css/, js/, data/countries.json
sw.js, manifest.webmanifest, favicon.svg, .nojekyll
```

Після зміни коду збільште `VERSION` у `sw.js`, щоб повторні відвідувачі отримали оновлення.
